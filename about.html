这个网站是什么

个人投资研究的公开记录：十大金股周报沉淀每周观点与跟踪名单， 组合追踪用两个等权组合的净值实证选股思路， 个股深度与财报点评留存长文研究， 基金研究分享公募 / 私募价值派基金的系统方法， 大师研习整理国内外价值投资代表人物的学习笔记。

公开意味着每一笔判断都留痕、都可被检验——研究的目的不是正确，而是可证伪。

研究风格

  • 价值投资：买股票就是买公司，用深度研究换取持有信心
  • 事实 / 观点分级：数据与判断分开标注，数字带口径、观点带主语
  • 估值口径标准化：统一方法、统一基准，拒绝拍脑袋
  • 实证驱动：组合净值每周公开，跑不赢指数就承认

内容栏目

  • 十大金股周报：每周日更新（与公众号同步）
  • 个股深度研究：如 Alphabet（GOOGL）系列
  • 财报点评：中概股业绩解读，沿用事实/观点分级
  • 基金研究：公募 / 私募价值派基金的筛选与跟踪方法
  • 大师研习：国内外价值投资代表人物的学习总结
  • 组合追踪：价值红利10只 vs 全枢约12只 vs 沪深300/中证红利

技术栈

  • 数据：AKShare 抓取 A股 / 港股 / 美股日线收盘价
  • 图表：matplotlib + 静态 HTML/CSS
  • 托管：Cloudflare Pages · 域名 hjangel.com（美橙互联注册）
  • 更新：每周本地脚本抓数 → git push → 自动部署
